# Account Signup Form 💻

A responsive and visually clean Account Signup Form built using **HTML, CSS, and JavaScript**.

This project demonstrates structured form design, password validation, and clean UI styling as part of my front-end development practice.

## 📌 Features

- Full account registration form
- Input validation using HTML attributes
- Strong password pattern enforcement
- Confirm password match validation (JavaScript)
- Country selection with datalist (African countries)
- File upload for profile picture
- Terms & Conditions agreement checkbox
- Separate Terms & Conditions page
- Responsive and centered layout
- Clean and modern UI styling

---

## 🔐 Password Requirements

The password must:

- Be 10–32 characters long
- Contain at least one uppercase letter
- Contain at least one lowercase letter
- Contain at least one number
- Contain at least one special character
- Contain no spaces
